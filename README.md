# Мультгерои Кыргызстана — домашнее задание React, урок 2

Одна страница с **9 персонажами мультфильмов и аниме** и вымышленными учебными данными.

## Запуск

Откройте папку проекта в VS Code и выполните:

```bash
npm install
npm run dev
```

Проверить сборку:

```bash
npm run build
```

## Что реализовано

- `src/components/UserList.jsx` — массив из 9 объектов и список через `map()`;
- `src/components/UserCard.jsx` — данные через пропс `user`;
- условный рендеринг `Active === true`;
- компоненты Ant Design: `Card`, `Avatar`, `Tag`;
- CSS, адаптивная сетка 3 / 2 / 1 колонка.

**Важно:** возраст, город в Кыргызстане и статусы вымышленные, придуманы для упражнения. Картинки подгружаются из внешних URL и могут быть недоступны; в таком случае вместо изображения показывается эмодзи персонажа.
